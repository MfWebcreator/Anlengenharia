# ANL Engenharia & Soluções Técnicas ⚙️

Website institucional premium de engenharia mecânica aplicada à manutenção industrial, inspeção e conformidade normativa.

## 🚀 Tecnologias e Recursos Visuais
- **React 18 + Vite**
- **Tailwind CSS** com tipografia editorial (`Inter Tight`, `Manrope`, `Poppins`)
- **Lenis Smooth Scroll** para navegação fluida
- **Framer Motion** para animações 3D perspective tilt, masked text reveal palavra por palavra e transições
- **WebGL Fragment Shader** reproduzindo as ondas 3D orgânicas e translúcidas em tons verde/teal institucional
- **Canvas Particles** para poeira de luz/estrelas espaciais
- **Cursor Dinâmico Inversor de Cores** com `mix-blend-mode: difference` e expansão em hover
- **Diagrama Esquemático Interativo** com pulsos SVG conectando as 4 frentes de serviço ao chip central da ANL
- **100% Fidedigno ao Portfólio Oficial (Slides 1 a 10)**
